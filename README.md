# 32-bit 5 staged pipelined RISC-V processor
A 32-bit 5-stage pipelined RISC-V processor is a CPU design that executes instructions through five stages: Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB).

Implemented the ALU, Control Unit, Register File, and Memory modules in Verilog.
Supported R-type, I-type, Load/Store, and Branch instructions based on the RISC-V ISA.
Pipelining allows multiple instructions to be processed simultaneously, improving instruction throughput and overall processor performance.
